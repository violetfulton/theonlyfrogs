theonlyfrogs / collection desk

🐸 Your Sofi binder

Paste your collection pages, tidy the details, then save your cards and artwork.

1. Paste collection pages

Copy your collection rows from Discord and paste them here. Plain text and Markdown both work—no extra formatting needed. You can paste several pages together; repeated card codes are combined.

Pasting adds or updates cards. It does not remove cards from other pages. Reload discards unsaved edits.

2. Link or attach artwork

Use Frog Pond below to link artwork already uploaded to R2, or select local files here. To save new artwork, view each card with sv CARD_CODE yourself and save its original image. Rename it to the card code, for example adam.png or o6tnjw.gif. Select images below to match them automatically. Animated GIF/WebP files are preserved.

Match artwork from Frog Pond / R2

Upload images to Frog Pond named after their card codes. This matches the original filename or code title to the random public permalink. Import your collection rows first. Changes are previewed until you save.

Connect from a computer that can open Frog Pond

Enter credentials here locally if Frog Pond requires them. They are used for these read requests and are never saved to the collection or website. Close this tab when finished.

Import a JSON listing exported on your PC

On your PC, open the Frog Pond image listing while signed in. Save that JSON response to a file (Ctrl+S), or copy its text. Transfer the file to your Mac if needed. This is metadata only; you do not need to transfer the images.

Duplicate images for a code are reported for review. Cards without a match keep their current artwork, tags and showcase selection. No uploads or deletions are made in Frog Pond.

Use images hosted on another server

Upload the code-named files to your server first. They must open directly without a login. This importer links to them; it does not upload to the server.

Empty means cards without an image. Paste codes to replace specific image links. A card named adam with PNG selected links to the folder URL + adam.png.

3. Tag lots of cards at once

Import the cards first. Enter a tag name and paste its card codes, separated by spaces, commas or newlines. You can also paste the full collection rows for that tag. Use site for cards in your featured showcase; all imported cards remain available in the website's All cards view.

Tag changes are previewed here. Save collection + images applies them to your file.

Loading your saved cards…

4. Review your cards

Sofi sometimes shortens series names. Fill those in here. Unknown edition icons are kept for reference; their type is not guessed. Showcase cards have the site tag; all cards can be browsed on the website.

Then run your usual site build/deploy. Ctrl+C stops this importer.
